# BaytiCare

BaytiCare is a home services platform that connects users with freelancers, service providers, and furniture businesses in one place.  
The platform offers access to various home-related services such as carpentry, blacksmithing, furniture moving, furniture stores, and more.

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Spring Boot Framework
- MySQL Database
- Firebase

### Development Tools
- Visual Studio Code
- IntelliJ IDEA
